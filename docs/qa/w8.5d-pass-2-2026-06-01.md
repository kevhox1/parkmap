## Fix 1 verified — Park Until auto-fire from arrival-confirm: RESOLVED

**Architecture is correct.**

The arrival-confirm closure in `ContentView.swift` (around line 806) now reads:

```
parkPinService.save(car)
// endDriveMode() does NOT touch activeSheet, so the assignment below is safe.
endDriveMode()
// W8.5d pass-2 (QA Finding #1, Option B): auto-fire Park Until sheet
activeSheet = .parkUntil
```

This is exactly the 3-step sequence the brief required: (a) save, (b) end drive, (c) set sheet.

**`endDriveMode()` does not touch `activeSheet`** — confirmed by reading the function body (`ContentView.swift:1103–1109`). It sets `driveModeActive = false`, `activeRoute = nil`, `driveDestinationCoordinate = nil`, `driveModeDistanceMeters = nil`. Nothing else.

**`handleDriveModeChange(false)` does not touch `activeSheet`** — confirmed by reading the function body (`ContentView.swift:1273–1284`). The `false` branch calls `locationService.endDriveMode()`, nils out `drivingContextService` and `drivingContext`, resets `driveFollowEnabled`, deactivates the audio session, resets `finalApproachState` to `.outside`, and resets `arrivalPromptFired` to `false`. No `activeSheet` mutation.

**No clobbering path from the `.onChange(of: driveModeActive)` handlers.** There are two `.onChange(of: driveModeActive)` registrations in ContentView: one calls `handleDriveModeChange(active)`, the other calls `handleDriveCameraChange(active)`. Both confirmed to not touch `activeSheet`. SwiftUI batches the `endDriveMode()` → `driveModeActive = false` and `activeSheet = .parkUntil` mutations from the same run-loop iteration; `.onChange` handlers fire after the current view-update cycle, so they cannot race to nil out `activeSheet` before it presents.

**Spec amendment for AC-18 is accurate.** The amended `docs/w8.5d-final-approach-spec.md` AC-18 replaces the stale "fires naturally via pinDropped" wording with the explicit 3-step sequence, explicitly acknowledges the W7.5 pivot-to-standalone-toolbar still stands, and explains why the arrival-confirm path opts back into auto-fire (user has committed). The `endDriveMode()` safety comment is included. The amendment correctly captures Kevin's Option B decision.
