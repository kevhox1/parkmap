## What's working

- **Architecture is exactly right.** The CoordinatorActions reference-type box pattern cleanly solves the coordinator-reference problem without involving `updateUIView` in any camera logic. The action closures use `[weak coordinator]` captures (correct; avoids retain cycles). `makeUIView` wires the closures once; `ContentView` holds the box as `@State` (created once, stable reference across re-renders).

- **Pure-function extraction (`targetPitch`) is the correct test strategy.** By separating the pitch decision from the UIKit mutation, the tests exercise the logic without `MKMapView`, `UIWindowScene`, or run-loop gymnastics. The reverted code's test-infrastructure-in-production smell is fully eliminated.

- **`[deferred to PR-2]` comment seam is in exactly the right place** — inside `applyDriveCameraPitch` at the `centerCoordinateDistance` line. PR-2 can slot in the zoom logic without restructuring the method.

- **R-1 dead-band coexistence is correct by construction.** Because `applyDriveCameraPitch` is called only from `.onChange` (not from `updateUIView`), the pitch `setCamera` fires `regionDidChangeAnimated`, which triggers `updateUIView`, which calls `syncDriveHeading`. At that moment `heading == lastAppliedHeading` (or nil), so the dead-band returns early. No feedback loop is possible from the architecture alone — and `testHeadingDeadBand_afterPitchChange_duplicateHeadingIsSkipped` verifies the guard logic.

- **W85bTests and W85cTests changes are strictly mechanical call-site updates** — the new `coordinatorActions:` parameter added to `MapViewRepresentable`'s init required updating test instantiation sites. No assertions changed meaning.

- **Six new tests vs. spec minimum of 4** — engineer went beyond the minimum, adding `testPitchDecision_onEntry_returnsConstantValue` (guards against silent constant changes) and `testPitchDecision_onExit_restoresNonZeroPrior` (OQ-3 non-zero case).

- **Documentation quality is high.** AC-10 comment is present at every relevant site: `ContentView`'s `@State private var coordinatorActions`, the `.onChange` handler, `handleDriveCameraChange`, and `applyDriveCameraPitch`. The W8.5d reuse note and PR-2 seam notes are in place.
