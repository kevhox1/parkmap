### S-1 — Background-limitation alert

- Pass-1 status: Significant

- Verification:

`BackgroundNoteGate` struct added to `Services/Constants.swift` (lines ~84–115 in post-fix file). Key constant `driveModeBackgroundNoteShownKey = "wepark_dm_bg_note_shown"` exactly matches the spec-suggested name in R-3.

Alert requires explicit "Got It" dismissal — correct for a first-time disclosure that needs user acknowledgment (a toast would be too passive).

- `testDriveModeStart_subsequentTimes_gateReturnsFalse`: pre-sets key via `markShown()`, then calls `shouldShow()` 5 times and asserts false each time. Correct idempotency check.
