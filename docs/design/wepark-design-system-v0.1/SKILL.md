Read README.md in this folder first, then DESIGN_GUIDE.md and source/BRIEF.md (hard product rules).
The .dc.html files are HTML design references, not production code: recreate them in SwiftUI using the codebase's own patterns. WeParkTokens.swift is a starting point for tokens.
Apply the three rules to every screen: facts are flat; raised means press or earned; line style carries the answer.
Do not invent icons, a logo, or answers to the "Open decisions" in README.md. Ask the owner.
If invoked without other guidance, ask which screen or flow to implement.
