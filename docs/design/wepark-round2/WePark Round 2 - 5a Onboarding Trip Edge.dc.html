B14 · Plan a Trip

B18 · Empty, error and edge states

Two forms only. A problem that blocks the whole screen uses the full-screen scaffold: what happened, what still works, one flat button. A problem that limits one feature is a dashed coral row placed next to that feature, with its fix on the right. Map-level versions of no location, outside coverage, loading and offline are B2.5 to B2.8 in batch 1.

B18.1 · No location permission
Shown when Start driving or Locate is tapped without permission. Symbol above the headline: location.slash.fill.
B18.2 · Location only "While Using"
New part: limit row (dashed coral, flat, fix button 48 tall). Shown when location is set to While Using; the button opens iOS Settings, where Always can be chosen. Everything else on My Car is unchanged, because everything else still works.
B18.3 · Notifications off
The row sits directly above the reminder switch it explains. Symbol: bell.slash.fill.
B18.4 · Offline
Reminders already set are stored on the phone and still fire. Symbol: wifi.slash.
B18.5 · Server down
Symbol above the headline: exclamationmark.icloud.fill.
B18.6 · No curbs loaded
We couldn't load the curbs here
Nothing is drawn, so nothing here means park or don't. Read the signs on the street.
Try again
A blank map, never grey lines, so a failed load cannot be read as "no sign data".
B18.7 · Outside Manhattan
Opens from the button on B2.6. Suggest goes to the form in Settings (B15) with the neighborhood filled in.
B18.8 · Account or sign-in problem
Symbol above the headline: person.crop.circle.badge.exclamationmark.
B18.9 · First launch, no parked car
Your car token appears on the map once you've parked.
The hollow dashed token is the same "nothing here yet" mark used on the lock screen (B12.5).
