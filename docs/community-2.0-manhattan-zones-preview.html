Reading the map

North is up. Dashed horizontal lines are the named cross streets used as zone boundaries. Dashed vertical lines are a few approximate avenue/river reference longitudes for orientation only — real avenues drift east/west by latitude far more than a single vertical line can show (see the doc's Broadway-diagonal compromise write-up).

Box outline color = status (see legend). Numbers inside boxes are the row index in the table below, for boxes too small to fit a label.
